Document AI Assistant

This project is a backend API (Python FastAPI). It does not run on GitHub Pages alone — you run it on your PC or cloud, then open the web UI.

Why a link might not open:
  • saswatsomyasahu.github.io/saswat/ = portfolio site (enable GitHub Pages on the repo).
  • This page = project info (works after Pages is deployed).
  • Live chat UI = only at http://127.0.0.1:8000/ when you start the API locally.

Run locally (Windows)

cd projects/document-ai-assistant
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
REM Add OPENAI_API_KEY in .env
uvicorn app.main:app --reload

Then open:
http://127.0.0.1:8000/ (web UI)
http://127.0.0.1:8000/docs (Swagger)
