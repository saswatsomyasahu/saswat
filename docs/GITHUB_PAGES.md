# Enable portfolio website (GitHub Pages)

After this folder is on `main`:

1. Open [github.com/saswatsomyasahu/saswat/settings/pages](https://github.com/saswatsomyasahu/saswat/settings/pages)
2. **Build and deployment** → Source: **Deploy from a branch**
3. Branch: **main** · Folder: **/docs** · Save
4. Wait 1–3 minutes. Your site: **https://saswatsomyasahu.github.io/saswat/**

Add that URL to your CV, LinkedIn, and the profile README.
